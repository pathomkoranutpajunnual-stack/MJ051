Statement of Purpose

เรียงความแสดงเจตจำนงในการศึกษาต่อ

ข้าพเจ้ามีความสนใจในด้านสาธารณสุข เพราะเชื่อว่า "สุขภาพที่ดีของประชาชนคือรากฐานสำคัญของการพัฒนาสังคมอย่างยั่งยืน" ตลอดช่วงเวลาที่ศึกษาในระดับมัธยมศึกษา ข้าพเจ้ามุ่งหาประสบการณ์นอกห้องเรียน ทั้งในด้านการส่งเสริมสุขภาพ การดูแลอนามัยชุมชน และสิ่งแวดล้อม เพื่อเตรียมความพร้อมในการเรียนต่อด้านสาธารณสุขอย่างจริงจัง

ข้าพเจ้าเคยเข้าร่วมเป็นจิตอาสาที่สถานีอนามัยในชุมชน ได้ช่วยคัดกรองสุขภาพเบื้องต้น ตรวจวัดความดันโลหิตและเจาะเลือดตรวจเบาหวาน ให้ความรู้เรื่องการป้องกันโรค เช่น โรคไข้เลือดออก โรคชิคุนกุนยา และร่วมรณรงค์เกี่ยวกับโควิด-19 ประสบการณ์เหล่านี้ทำให้ข้าพเจ้าเข้าใจอย่างถ่องแท้ว่า "การสื่อสารกับชุมชนอย่างเข้าถึงและเข้าใจ เป็นหัวใจสำคัญที่สุดของการทำงานด้านสาธารณสุข"

ข้าพเจ้ามีความตั้งใจจะศึกษาต่อใน คณะสาธารณสุขศาสตร์ มหาวิทยาลัยมหิดล (วิทยาเขตศาลายา) เนื่องจากเชื่อมั่นในคุณภาพของหลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาสาธารณสุขศาสตร์ ที่มุ่งพัฒนาทั้งความรู้ทางวิชาการ ทักษะการคิดวิเคราะห์ และการทำงานเชิงระบบ โดยเฉพาะในบริบทของชุมชนที่มีความหลากหลาย

ในอนาคต ข้าพเจ้าหวังว่าจะสามารถนำความรู้และทักษะที่ได้รับจากมหาวิทยาลัยมหิดล กลับไปพัฒนาชุมชนของตนให้มีสุขภาวะที่ดีขึ้น และเป็นส่วนหนึ่งในการสร้างสังคมที่มีคุณภาพชีวิตที่ยั่งยืน

GitHub Pages Ready

คู่มือและไฟล์สำหรับการนำขึ้น GitHub Pages

เว็บไซต์นี้ได้รับการออกแบบโครงสร้างเป็น Single-File HTML ซึ่งสามารถนำไปเผยแพร่ออนไลน์ผ่าน **GitHub Pages** ได้ฟรีทันทีใน 3 ขั้นตอนดังนี้:

1

สร้าง Repository

สร้าง repository ใหม่บน GitHub เช่น academic-portfolio

2

อัปโหลดไฟล์ index.html

บันทึกโค้ดนี้เป็นชื่อไฟล์ index.html แล้วอัปโหลดไปยังสาขา main

3

เปิดใช้งาน Pages

ไปที่ Settings > Pages > เลือก Deploy from a branch (main / root)

.github/workflows/static.yml (อุปกรณ์เสริมสำหรับการ Auto-deploy) 
name: Deploy static content to Pages

on:
  push:
    branches: ["main"]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
