Field Practice & Community

ประสบการณ์การลงพื้นที่และงานสาธารณสุข

ประยุกต์ใช้องค์ความรู้ทางวิชาการสู่การปฏิบัติจริงในชุมชน การตรวจคัดกรองสุขภาพ และการส่งเสริมสุขภาพเชิงรุก

ตรวจคัดกรองสุขภาพเบื้องต้น & พาออกกำลังกาย

ร่วมเป็นผู้นำพาชาวบ้านออกกำลังกายเพื่อการดูแลสุขภาพเชิงป้องกัน พร้อมให้บริการตรวจคัดกรองสุขภาพเบื้องต้น ได้แก่ การวัดความดันโลหิต การตรวจระดับน้ำตาลในเลือด (เจาะเบาหวาน) และการประเมินภาวะสุขภาพในชุมชน

วัดความดันโลหิต ตรวจน้ำตาลเบาหวาน ผู้นำออกกำลังกาย

การสื่อสารสุขศึกษาภาษาชาวบ้าน

เน้นการสื่อสารให้ความรู้เรื่องการป้องกันโรคติดต่อในท้องถิ่น ไข้เลือดออก และโรคไม่ติดต่อเรื้อรัง (NCDs) ด้วยภาษาพูดง่ายๆ เป็นกันเอง ช่วยให้คนในชุมชนเข้าใจ เข้าถึง และนำไปปฏิบัติตัวได้จริง

การบริการด้วยหัวใจมนุษย์

"จุดที่ทำให้รู้สึกว่าเป็นตัวของตัวเองที่สุด คือการได้ลงพื้นที่ พบปะพูดคุย และช่วยเหลือให้ชาวบ้านมีสุขภาพที่ดีขึ้น"

Deployment Tutorial

ขั้นตอนการนำเว็บนี้ขึ้น GitHub Pages (ใช้งานฟรี)

คุณสามารถนำโค้ดไฟล์นี้ (`index.html`) ไปเปิดให้ออนไลน์เป็นเว็บไซต์ประวัติส่วนตัวได้ทันทีโดยใช้บริการฟรีของ **GitHub Pages** ตาม 4 ขั้นตอนง่ายๆ ดังนี้:

1 Step 01

คลัง GitHub Repository

เปิดไปยังคลังข้อมูลของคุณ MJ051 ซึ่งตั้งค่าเป็น Public ไว้แล้ว

2 Step 02

บันทึกชื่อ `index.html`

คัดลอกโค้ดทั้งหมดนี้ บันทึกไว้ในไฟล์ชื่อ index.html แล้วกด Upload files ขึ้นไปยัง Repository MJ051

3 Step 03

เปิดใช้งาน Pages

ไปที่เมนู Settings > Pages เลือก Branch เป็น main แล้วกด Save

4 สำเร็จ!
