Deployment Tutorial

ขั้นตอนการนำเว็บนี้ขึ้น GitHub Pages (ฟรี)

คุณสามารถนำโค้ดไฟล์นี้ (`index.html`) ไปเปิดให้ออนไลน์เป็นเว็บไซต์ประวัติส่วนตัวได้ทันทีโดยใช้บริการ **GitHub Pages** ตาม 4 ขั้นตอนง่ายๆ ดังนี้:

1 สร้าง Repository

สร้าง GitHub Repository

สมัครใช้งาน GitHub.com จากนั้นกดปุ่ม New Repository ตั้งชื่อเช่น moji-portfolio เลือกตั้งเป็น Public

2 อัปโหลดไฟล์

บันทึกไฟล์เป็น `index.html`

คัดลอกโค้ดทั้งหมดนี้ไปวางในไฟล์ชื่อ index.html แล้วกด Upload files ขึ้นไปยัง GitHub Repository ที่สร้างไว้

3 ตั้งค่า Pages

เปิดใช้งาน GitHub Pages

เข้าไปที่เมนู Settings > Pages ของ Repository นั้น ตรงหัวข้อ Source ให้เลือก Branch เป็น main หรือ master แล้วกด Save

4 สำเร็จ!

เข้าชมเว็บไซต์

รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://username.github.io/moji-portfolio/ สำหรับนำไปใส่อกตั้งหรือแนบเรซูเม่ได้ทันที!
